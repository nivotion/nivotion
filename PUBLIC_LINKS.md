## Download

Use **nivotion → Releases → v0.2.0-rc.1**. Download the named Windows ZIP, not a generated repository source archive. If the release is absent, a download is not yet available.

## Bug reports

Use **nivotion-feedback → Issues → New issue → Bug report**.

## UX feedback

Use **nivotion-feedback → Issues → New issue → UX feedback**.

## Improvement ideas

Use **nivotion-feedback → Issues → New issue → Improvement idea**. Suggestions do not create roadmap commitments.

## Discussions

Use **nivotion-feedback → Discussions**: [General feedback](https://github.com/nivotion/nivotion-feedback/discussions/categories/general-feedback), [Ideas](https://github.com/nivotion/nivotion-feedback/discussions/categories/ideas), [Q&A](https://github.com/nivotion/nivotion-feedback/discussions/categories/q-a), [Early impressions](https://github.com/nivotion/nivotion-feedback/discussions/categories/early-impressions). If the categories are unavailable, wait for the community channels to become available.

## Private security reporting

Use [Report a vulnerability](https://github.com/nivotion/nivotion/security/advisories/new) in the product repository. Private vulnerability reporting is enabled. If it is unavailable, wait for the private channel. Never post vulnerability details in public Issues or Discussions.

Do not upload private or sensitive CSV contents. Use a tiny synthetic reproduction and redact names, emails, customer data, local paths, tokens and private business data from screenshots and logs.
