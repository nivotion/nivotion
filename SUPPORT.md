# Feedback for the First Public Experimental Preview

This is NIVOTION's first public Experimental Preview. It is an early build, so rough edges are expected. Every useful bug report, confusing moment, workflow idea, missing detail and general impression helps us improve it. Suggestions are welcome; they are not roadmap commitments.

The product repository **nivotion** hosts downloads and documentation. Use the separate **nivotion-feedback** repository under the same GitHub owner for normal feedback:

| What you want to share | Where to go |
| --- | --- |
| Reproducible bug | Issues → Bug report ([route](PUBLIC_LINKS.md#bug-reports)) |
| Confusing controls or wording | Issues → UX feedback ([route](PUBLIC_LINKS.md#ux-feedback)) |
| A concrete improvement | Issues → Improvement idea ([route](PUBLIC_LINKS.md#improvement-ideas)) |
| Questions or open feedback | Discussions → Q&A, General feedback or Early impressions ([route](PUBLIC_LINKS.md#discussions)) |

Do not upload private or sensitive CSV contents. If data is needed, create a tiny synthetic CSV that reproduces the issue. Redact names, emails, customer data, local paths, tokens and private business data from screenshots, logs and attachments.

Use the version/build from Settings and include steps, expected and actual behavior. Czech and English reports are welcome. No response time or implementation commitment is promised.

Security vulnerabilities belong in the product repository's private vulnerability reporting mechanism, never in public Issues or Discussions. If the private route is unavailable, wait until it is enabled; do not post the details publicly. Read [SECURITY.md](SECURITY.md).
