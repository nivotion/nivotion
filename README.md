# NIVOTION V2 · Experimental Preview

Your files. Ready for what comes next.

Review, prepare and export CSV, PDF and XLSX files locally on your Windows desktop.

**0.2.0-rc.1 · Windows x64 · English / Čeština · Dark / Light**

[Download the complete Windows ZIP](https://github.com/nivotion/nivotion/releases/download/v0.2.0-rc.1/NIVOTION_0.2.0-rc.1_WINDOWS_X64_EXPERIMENTAL_PREVIEW.zip) · [What's new](WHATS_NEW.md) · [Quick Start](QUICKSTART.md)

| Work with | Prepare |
| --- | --- |
| CSV | Review a file, trim cell whitespace and optionally remove exact duplicate original rows. Combine compatible CSVs in the displayed order. |
| PDF | Extract native text, inspect ruled table candidates, or explicitly run local OCR in Czech, English or both. Review the result before TXT or CSV export. |
| XLSX | Inspect worksheets, select one, then prepare a text table with cleanup, rename/reorder and find/replace options. Export CSV or a new text-table XLSX. |

Add mixed files to one session inventory. Additional files append in order. The inventory lasts for the current application session; it is not a saved workspace. One expensive operation runs at a time.

**Review → Prepare → Export.** Originals remain unchanged. A prepared draft is not an export. Choose a new destination explicitly; existing outputs are refused. Each export includes a provenance JSON sidecar.

This is an unsigned Experimental Preview, not a stable or production-certified release. OCR can make mistakes; review its output. Spreadsheet exports do not preserve workbook formatting, charts or formulas. No AI, background agent, cross-format merge or general conversion is included.
