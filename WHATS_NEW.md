# What's new in NIVOTION 0.2.0-rc.1

## More of your work, in one place.

NIVOTION V2 expands the first CSV preview into a local workspace for CSV, PDF and spreadsheets.

- **One mixed session.** Add CSV, PDF and XLSX files together. New files append to your session inventory in a predictable order.
- **PDF, with a way through scans.** Review native text and table candidates, with explicit local OCR in Czech, English or both.
- **Worksheets ready to prepare.** Select a sheet, clean up a text table and review warnings before export.
- **A clearer path to a result.** Shared Review, Prepare and Export actions, persistent session context and readable provenance details.
- **Small interactions, better resolved.** Improved scrolling and touchpad behavior, safer mouse-wheel handling, refined checkbox alignment and more consistent English/Czech copy.
- **A steadier runtime.** Sequential work execution, source/destination checks, resource limits and explicit export remain central to every workflow.

Experimental Preview for Windows x64. OCR needs human review. Session inventory is not saved across restarts. Spreadsheet exports are text tables, not full workbook round-trips. No AI or background automation is included.
